Common questions

Can we import our existing data?

Yes — Settings → Data import takes Excel/CSV/ZIP with a dry-run check and an error report before anything is written.

Does it do CBSE grading and board exports?

Yes — a 9-point grading scheme in Academics, and a CBSE List of Candidates export in Reports.

Is it multi-campus?

Yes — multi-tenant with per-campus scoping and a branch switcher for group administrators.

Can parents pay fees online?

An online payment gateway is on the roadmap; counter and bank collection are recorded today.
